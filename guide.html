0. 왜 B.AI인가 — 지금 이벤트 (2026-09-22 기준)

항목내용
토큰 1+1 충전BNB Chain으로 온체인 결제하면 충전액의 +100% 보너스. 카드·기타 일반 충전은 +50%. (보너스 크레딧은 지급 후 30일 유효 — 쓸 만큼만 충전)
90% 할인 모델DeepSeek-V4.1-Flash, GLM-5.3-Flash, Qwen3.8-Flash가 표준가의 10%. 예: DeepSeek 출력 $1.20→$0.12/1M 토큰. GLM-5.3(풀) 10%·GLM-5.2 40% 할인.
속도서브에이전트 여러 개 물려도 100 tok/s 이상 나옵니다. 무료 티어 대기열·타임아웃 없음.
한 키로 전부OpenAI 호환 API 한 곳(https://api.b.ai/v1)에서 DeepSeek·GLM·Qwen·MiniMax·Kimi에 GPT·Claude·Gemini까지. 메인/서브 나눠 쓸 때 키 3~4개 발급할 필요 없음.

※ 할인·보너스 조건과 기간은 B.AI가 바꿀 수 있습니다. 최신은 공식 프로모션 페이지와 충전 화면 표시가 기준.

얼마나 드나? DeepSeek-V4.1-Flash 할인가는 입력 $0.03 / 출력 $0.12 (1M 토큰, 피크 기준). $5 충전(+보너스 $2.5~5)이면 코딩 작업 수십 시간 분량. 무료 티어에서 하루 20번 막히던 사람이면 체감이 다릅니다.

1. 준비물 (5분)

  • 구글 계정 또는 Web3 지갑(MetaMask 등) — B.AI 로그인용. 둘 중 하나면 됨.
  • 충전 수단: 카드(Stripe) 또는 BNB Chain 지갑(1+1 받으려면 이쪽).
  • 인터넷 되는 윈도우 PC 또는 맥.
  • 이미 free-gjc-starter를 깔았다면 3번은 건너뛰고 4번부터. 두 세팅은 따로 격리(~/.gjc-free vs ~/.gjc-bai)돼서 충돌 없음.

2. "터미널" 여는 법

터미널 = 컴퓨터에 글자로 명령을 내리는 창입니다. 여기다 아래 명령들을 복사-붙여넣기합니다.

🪟 윈도우
  1. 키보드 ⊞ 윈도우 키를 누릅니다.
  2. 터미널 이라고 칩니다. (안 뜨면 powershell)
  3. Windows Terminal 또는 Windows PowerShell 클릭 → 창이 뜹니다.
🍎 맥
  1. ⌘ + 스페이스 를 동시에 → 검색창.
  2. 터미널 또는 terminal 입력.
  3. 터미널(Terminal) 클릭.
복사-붙여넣기 & 실행 — 아래 상자 명령을 복사(Ctrl+C, 맥 ⌘+C) → 터미널에 붙여넣기(윈도우: 마우스 오른쪽 클릭, 맥: ⌘+V) → Enter 를 눌러야 실행됩니다.

3. gjc 설치

이미 gjc --version이 찍히면 건너뛰세요.

🪟 윈도우 (PowerShell)
irm bun.sh/install.ps1 | iex

👉 끝나면 창을 닫고 터미널을 새로 여세요. 그다음:

bun install -g gajae-code
🍎 맥 / 리눅스
curl -fsSL https://bun.sh/install | bash

👉 끝나면 터미널을 새로 여세요. 그다음:

bun install -g gajae-code
확인: gjc --version 을 치고 버전 숫자가 나오면 성공.
❔ command not found / 인식할 수 없습니다 → 터미널을 완전히 닫고 다시 여세요.

4. 이 세팅 설치

🪟 윈도우
git clone https://github.com/yazzang-homelab/bai-gjc-starter.git
cd bai-gjc-starter
powershell -ExecutionPolicy Bypass -File .\install.ps1
🍎 맥 / 리눅스
git clone https://github.com/yazzang-homelab/bai-gjc-starter.git
cd bai-gjc-starter
bash install.sh

❔ git ... 없음 → 윈도우는 git-scm.com에서 설치, 맥은 xcode-select --install 후 다시 시도.
❔ 이 시스템에서 스크립트를 실행할 수 없으므로 → 위 명령의 -ExecutionPolicy Bypass로 실행하면 됩니다.

설치되는 것: 설정 ~/.gjc-bai/agent/ + 런처 bai-gjc. 기존 gjc·free-gjc는 건드리지 않습니다.

5. B.AI 가입 → 충전 → API 키 발급

  1. 가입: chat.b.ai/chat?invite_code=9MVP9L 접속 → 우상단 Log in → 구글 로그인 또는 지갑 연결.
    위 링크는 이 가이드 작성자 레퍼럴입니다. 가입자는 손해 없고, 작성자에게 소량 코인이 들어옵니다. 싫으면 https://chat.b.ai/chat로 직접 가세요.
  2. 충전: 왼쪽 메뉴 Top up.
    • 1+1 BNB Chain 선택 → 지갑에서 USDT/BNB 등 전송. 몇 분 뒤 2배로 들어옴.
    • 1+0.5 카드(Stripe)/기타 → 1.5배.
    처음엔 $5~10만. 보너스는 30일 유효.
  3. API 키: 왼쪽 메뉴 API Key(또는 설정) → Create → 이름 아무거나 → 나온 sk-... 복사.
키는 생성 직후 한 번만 보이는 경우가 많습니다. 바로 복사해서 다음 단계로. 주소창이 chat.b.ai 또는 chat.bankofai.io인지 결제 전에 꼭 확인.

6. 키를 컴퓨터에 넣기

여기에_키 부분만 방금 복사한 진짜 키로 바꿔서 붙여넣으세요.

🪟 윈도우 (PowerShell)
setx BAI_API_KEY "여기에_키"

👉 그리고 터미널을 닫고 새로 여세요. (setx는 새 창부터 적용)

🍎 맥 / 리눅스
echo 'export BAI_API_KEY="여기에_키"' >> ~/.zshrc
source ~/.zshrc

(오래된 셸이면 ~/.zshrc → ~/.bashrc 로 바꿔 쓰세요.)

7. 모델 고르기

기본값이 이미 전부 90% 할인 모델이라 그냥 써도 됩니다.

역할기본 모델할인비고
메인(default)·architectbai/deepseek-v4.1-flash90%552B MoE, 1M 컨텍스트, 이미지 입력 가능
executorbai/glm-5.3-flash90%1M 컨텍스트, 코딩 일꾼
planner·criticbai/qwen3.8-flash90%1M 컨텍스트, 저가

바꾸고 싶으면 ~/.gjc-bai/agent/config.yml의 modelRoles:에서 한 줄만 교체. 준비된 후보:

bai/glm-5.3          # GLM-5.3 풀사이즈 (표준가의 90%)
bai/qwen3.8-max      # Qwen 최상위 (표준가)
bai/minimax-m3       # MiniMax M3, 1M ctx, 저가
bai/deepseek-v4-flash  # 예전 이름 — V4.1로 자동 라우팅

B.AI에 있는 다른 모델(Kimi K3, GPT, Claude 등)도 ~/.gjc-bai/agent/models.yml에 항목 추가하면 같은 키로 됩니다. 정확한 id는 curl https://api.b.ai/v1/models -H "Authorization: Bearer $BAI_API_KEY"로 확인. Claude/GPT는 할인 없음 — 실수로 고르지 않게 기본 목록엔 뺐습니다.

🕐 DeepSeek 시간대 요금: 중국 평일 09–12시·14–18시(한국 10–13시·15–19시)가 피크로 2배. 그 외·주말은 오프피크(절반). 할인 10%는 양쪽에 동일 적용.

8. 확인 & 첫 대화

bai-gjc config get modelRoles       # 역할별 모델이 찍히면 설정 OK
bai-gjc -p --no-session "안녕? 넌 누구야?"
AI가 대답하면 성공! 🎉 이제 이렇게 씁니다: 
bai-gjc                              # 대화형으로 켜기
bai-gjc "파이썬으로 계산기 만들어줘"    # 한 번에 시키기
잔액은 B.AI 왼쪽 메뉴 Usage에서 요청별 토큰·크레딧까지 보입니다. 평소 gjc·free-gjc와 완전히 따로 돌아갑니다.

문제 해결

증상해결
BAI_API_KEY 가 비어 있습니다6번대로 키 넣고 터미널 새로 열기.
401 / Invalid token키 오타·잘못 복사. B.AI에서 키 다시 만들어 6번 재실행.
402 / insufficient balance / 잔액 부족연결은 됨. Top up에서 충전. 보너스 크레딧 30일 만료도 확인.
403 access_deniedPremium 태그 모델(일부 GPT/Claude)은 계정 등급 제한. 기본 할인 모델로 되돌리기.
no match / 모델 못 찾음B.AI가 모델 id를 바꾼 것. curl https://api.b.ai/v1/models -H "Authorization: Bearer $BAI_API_KEY"로 현재 id 확인 후 ~/.gjc-bai/agent/models.yml·config.yml 수정. DeepSeek은 deepseek-v4-flash로 바꿔보기.
400 + 이미지 관련DeepSeek은 이미지를 system/assistant 위치에 넣으면 400. user 메시지에서만 첨부.
Provider stream timed out런처가 첫 응답 5분/유휴 3분으로 잡아둠. 그래도 나면 대화가 너무 긴 것 — /compact 또는 새 세션.
B.AI 접속이 안 됨대체 주소 https://chat.bankofai.io/chat. 안드로이드 앱의 Service Availability에서 API 주소 확인 가능.
🗨️ 혼자 해결 안 되면 — 오픈카톡: open.kakao.com/o/pW7JOXDi (이 세팅 올린 사람이 직접 답변. gjc 원작자·B.AI와는 무관)
